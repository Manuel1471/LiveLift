# 5.3 — Native class commands

This evidence covers experimental LiveLift and is for maintainers verifying
the class-command increment of roadmap delivery 5.3.

## Acceptance

- Compiling a literal class command produces the same binding that Phoenix
  encodes. The compiler preserves mixed pipe order and supports the bound
  element and simple descendant selectors.
- A comparison with unmodified LiveView checks add, remove, toggle twice,
  an optimistic render and a server patch. Disabling the source or stopping
  the click before it reaches Phoenix leaves the DOM effects unchanged.
- Invalid class tokens, computed arguments, transitions, document selectors,
  and delayed bindings report an actionable error with a source location.
- Templates without a class command omit the tracker. The shared runtime
  stays within its 8 KiB gzip budget.

The original [JS spike](../liveview-js-spike.md) reproduces the class loss
that motivated this increment. [ADR-0003](../decisions/ADR-0003-native-js-class-patches.md)
describes why the tracker follows Phoenix's frame boundaries.

## Security review and limits

The tracker looks up the click binding in compiler-produced metadata and
reads only literal operations and relative selectors. A stopped click
does not record effects. The change introduces no event parameters,
persisted data, telemetry, new state fields, wire messages, HTML parsing
or JavaScript evaluation. There is no change to executable URL or
unsafe state-key checks. Compiler tests cover unsupported scopes,
dynamically supplied names and raw command encodings. The target uses
the default LiveView selector behavior. A replaced node starts with
its template classes.

## Environment and size

Local verification on 2026-11-21 used LiveView 1.2.13, macOS arm64 on Apple
M4, Elixir 1.20.2, OTP 29 and Node 26.5.0. Browser runs use Chromium
158.0.8127.18, Firefox 159.0 and WebKit 27.2.

The shared runtime measured 8,179 bytes gzip versus 8,182 on `6648599`.
It uses the [same esbuild and gzip command](5.2-changeset-form-projection.md#environment-and-size).
The split demo initially loads 55,285 bytes gzip versus 55,292 in the
[previous increment](5.3-native-focus.md) using `python3 bench/island_bundle.py`.
The eager demo loads 63,362 bytes gzip. Compiled class bindings and their
tracker load with the native counter chunk when assets are split.
The reference app from `bench/phoenix_bundle.sh` measured 47,351 bytes gzip
with Phoenix and 55,842 with LiveLift, compared with 55,848 with LiveLift
in the previous increment.
