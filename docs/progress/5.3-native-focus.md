# 5.3 — Native focus commands

## Acceptance for this increment

- Literal `focus` and `focus_first` bindings encode the same commands as
  Phoenix, including target and pipe order.
- Chromium, Firefox and WebKit run the commands before and after a marked
  update. The focused node and the exact click binding survive the update.
- E053 rejects raw encoded events, expressions, document selectors,
  dispatch and class mutations at their template location.
- The shared runtime stays unchanged. The supported calls add only
  their encoded values to the opted-in template.

## Scope

The [spike](../liveview-js-spike.md) establishes focus behavior for
surviving targets and shows that external class changes can be lost.
[ADR-0002](../decisions/ADR-0002-native-js-focus.md) records the initial
allowlist. Sticky mutations and the rest of 5.3 remain open.

## Security review

The compiler parses literal syntax and calls only the two allowed native
functions with checked arguments. It never evaluates the template
expression. Descendant selectors have a bounded grammar. No new runtime
input, state field, telemetry, DOM insertion mechanism or event envelope
is introduced. Negative tests cover computed attributes, raw command
encodings and other command types.

## Environment and size

The baseline is `c2fb110`. Local verification on 2026-11-21 used macOS
arm64 on Apple M4, Elixir 1.20.2, OTP 29, Node 26.5.0, Chromium
158.0.8127.18, Firefox 159.0, and WebKit 27.2.

The shared runtime measured 8,182 bytes gzip on both revisions with
the same esbuild and gzip command recorded in the
[projection evidence](5.2-changeset-form-projection.md).
`python3 bench/island_bundle.py` measured the split demo entry at
55,292 bytes gzip versus 55,291 at the earlier baseline. The commands
are carried by the counter's view chunk.
The reference application from `bench/phoenix_bundle.sh` measured 47,351
bytes gzip without LiveLift and 55,848 with it, matching the previous run.
