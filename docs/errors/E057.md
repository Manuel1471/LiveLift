# E057 — Unsupported event parameters

For app developers using the experimental LiveLift compiler.

Marked handlers can read literal string keys from event params. Nested paths are limited to four safe segments.

Illustrative rejection

```elixir
params[key]
```

Illustrative correction

```elixir
params["profile"]["name"]
```

Leave the handler unmarked for dynamic keys or further parameter processing. Treat inbound params as untrusted.
