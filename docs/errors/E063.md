# E063 — Unsupported event binding

For app developers using the experimental LiveLift compiler.

Marked form handlers support the form controls, parameter names and targets in the [native guide](../native-livecomponent.md).

Illustrative rejection

```heex
<form phx-change="toggle"><input type="checkbox" name="active" /></form>
```

Illustrative correction

```heex
<form phx-change="rename"><input type="text" name="name" /></form>
```

Keep the original checkbox form and leave its handler unmarked. Move markup that requires unsupported targets or debounce forms outside the LiveLift island.

A marked `phx-change` on a control outside a form requires a flat, static
field name. Put the binding on the form to send a nested name such as
`profile[note]`. Keep a multiple-select's change handler unmarked so
Phoenix receives all selected values.
