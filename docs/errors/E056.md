# E056 — Unsupported handler expression

For app developers using the experimental LiveLift compiler.

The marked handler evaluates an expression outside the [client language](../language.md). This includes arbitrary calls into server modules.

Illustrative rejection

```elixir
assign(socket, :count, System.monotonic_time())
```

Illustrative correction

```elixir
assign(socket, :count, socket.assigns.count + 1)
```

Remove `@client true` from the handler if the action needs an actual server clock, database query or another server-only facility.
