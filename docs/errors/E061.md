# E061 — Unsupported HEEx binding

For app developers using the experimental LiveLift compiler.

A binding can read assigns or scoped values in the [supported template subset](../language.md). Unsupported calls and attributes fail at compile time.

Illustrative rejection

```heex
<p>{String.upcase(@name)}</p>
```

Illustrative correction

```heex
<p>{@display_name}</p>
```

Assign the display value in LiveView. Render markup that needs arbitrary HEEx in a parent or sibling outside the LiveLift island.
