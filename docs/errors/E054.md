# E054 — Unsupported draft field or form

For developers using experimental LiveLift draft restoration.

Put `data-live-lift-draft` on a named text input or textarea inside a
form with an `id` and a `phx-submit` binding. Use that form as the
field's owner. If the form also has `phx-change`, set
`phx-auto-recover="ignore"` so a reconnect does not send restored text
as a validation event. A literal scope requires 1 to 128 ASCII letters,
digits, underscores or hyphens.

The [native form](../../examples/demo/lib/live_lift_demo_web/live/native_form_component.ex)
shows the supported form. Remove the draft attribute to leave the
control under ordinary LiveView behavior.
