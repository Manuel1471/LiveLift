# E062 — Unsupported function component

For app developers using the experimental LiveLift compiler.

An island can expand local function components with a literal `~H` body, explicit props and at most one default slot.

Illustrative rejection

```heex
<MyAppWeb.Badges.badge label={@label} />
```

Illustrative correction

```heex
<.badge label={@label} />
```

Define `badge/1` locally with a supported body. Render remote components or named slots in a parent or sibling outside the LiveLift island.
