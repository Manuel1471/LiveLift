# E059 — Unsupported native timer

For app developers using the experimental LiveLift compiler.

A native timer in a marked handler needs bounded literal arguments. The root LiveView owns its mailbox. A LiveComponent uses `send_update_after/3` with its own target and the default update callback.

Illustrative rejection

```elixir
Process.send_after(self(), :finish, delay)
```

Illustrative correction

```elixir
Process.send_after(self(), :finish, 250)
```

Keep an unguarded `handle_info(:finish, socket)` clause before any catch-all in the LiveView. Remove `@client true` from the scheduling handler for dynamic delays or other targets.
