# E053 — Unsupported native click command

For app developers using experimental LiveLift.

A `phx-click` inside an island can use a literal
`Phoenix.LiveView.JS.focus` or `Phoenix.LiveView.JS.focus_first` call.
The caller can focus the element itself or use a literal descendant
target. Keep the chain to eight calls and the expression to 1,024 bytes.

For example, a document selector fails to compile in an island.

```elixir
Phoenix.LiveView.JS.focus(to: "#target")
```

Use an inner target on a container that owns the destination.

```elixir
Phoenix.LiveView.JS.focus(to: {:inner, "#target"})
```

The selector can be a simple `#id` or `.class` of up to 64 identifier
characters after the prefix. The examples are illustrative. The
[native counter fixture](../../examples/demo/lib/live_lift_demo_web/live/native_counter_component.ex)
contains tested bindings.

Keep computed command expressions, raw command JSON, and operations
that mutate classes or attributes outside the LiveLift island. A named
LiveView event also works inside the island.
