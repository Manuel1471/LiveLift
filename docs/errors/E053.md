# E053 — Unsupported native click command

For app developers using experimental LiveLift.

A `phx-click` inside an island can use a literal
`Phoenix.LiveView.JS` call from `focus`, `focus_first`, `add_class`,
`remove_class`, and `toggle_class`. Use the bound element or a literal
descendant target. Keep the chain to eight calls and the expression to 1,024 bytes.

For example, a document selector fails to compile in an island.

```elixir
Phoenix.LiveView.JS.focus(to: "#target")
```

Use an inner target on a container that owns the destination.

```elixir
Phoenix.LiveView.JS.focus(to: {:inner, "#target"})
```

The selector can be a simple `#id` or `.class` of up to 64 identifier
characters after the prefix. The examples are illustrative. The
[native counter fixture](../../examples/demo/lib/live_lift_demo_web/live/native_counter_component.ex)
contains tested bindings.

Class commands take one to eight literal names. A name starts with an
ASCII letter or underscore and uses up to 64 ASCII letters, digits,
underscores and hyphens. Use immediate bindings with the default target
selector. For transitions, delayed clicks, document selectors, arbitrary
attribute mutations, computed commands and raw command JSON, place the
binding outside the island. For state changes inside the island, use a
named LiveView event.
