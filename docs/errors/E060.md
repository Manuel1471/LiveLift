# E060 — Unsupported render or list shape

For app developers using the experimental LiveLift compiler.

The opted-in view must return a literal `~H` template. Give each native repeated element an ID from its item so the browser can preserve its DOM identity.

Illustrative rejection

```heex
<li :for={item <- @items}>{item.name}</li>
```

Illustrative correction

```heex
<li :for={item <- @items} id={item.id}>{item.name}</li>
```

Keep delegated renders or lists without stable keys in a LiveView or LiveComponent without `use LiveLift`.
