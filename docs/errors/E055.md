# E055 — Unsupported marked handler

For app developers using the experimental LiveLift compiler.

LiveLift needs a literal event name, one unguarded clause per marked event and a supported socket update.

Illustrative rejection

```elixir
def handle_event(event, _params, socket), do: {:noreply, socket}
```

Illustrative correction

```elixir
def handle_event("inc", _params, socket), do: {:noreply, update(socket, :count, &(&1 + 1))}
```

Leave the handler unmarked to use Phoenix's normal event handling.
