# E058 — Unsupported private helper

For app developers using the experimental LiveLift compiler.

A private helper called by a marked handler must use unguarded clauses, supported expressions and bounded expansion.

Illustrative rejection

```elixir
defp add_one(n) when is_integer(n), do: n + 1
```

Illustrative correction

```elixir
defp add_one(n), do: n + 1
```

Remove `@client true` from the caller when it needs guarded helpers, recursion or other server logic.
