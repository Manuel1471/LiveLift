# E064 — Unsafe markup or parameter name

For app developers using the experimental LiveLift compiler.

LiveLift rejects executable markup, forbidden attribute values and unsafe event parameter keys.

Illustrative rejection

```heex
<a href="javascript:bad">Open</a>
```

Illustrative correction

```heex
<a href="/items">Open</a>
```

Use safe URLs and event bindings in LiveView too. Put event logic in a normal server-side `handle_event/3` if it needs server access.
