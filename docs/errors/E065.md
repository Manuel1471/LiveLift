# E065 — Invalid HEEx syntax

For app developers using the experimental LiveLift compiler.

The parser could not read the template at the indicated line and column.

Illustrative rejection

```heex
<section><span></section>
```

Illustrative correction

```heex
<section><span></span></section>
```

Fix the markup before using it in any LiveView. Compiling plain LiveView HEEx also requires well-formed markup.
